# Backend (Flask) - Community Housing (sample)

This is a simple Flask-based backend with in-memory data for demonstration.
You will replace or connect this with AWS Lambda/API Gateway or containerize for Amplify.

Run locally:

```bash
python -m venv venv
source venv/bin/activate    # or venv\Scripts\activate on Windows
pip install -r requirements.txt
python app.py
```
